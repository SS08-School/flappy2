# Asset credits

Flappy Bird was created by **Dong Nguyen / .GEARS**. This project recreates its gameplay for widescreen browsers.

The only runtime asset is the uploaded **Mobile - Flappy Bird - Miscellaneous - General Sprites (v1.3).png**, copied unchanged to `public/assets/flappy/official-v1.3.png`.

SHA-256: `e905c929c0de3d59c565d8903db7f3ca27cd78fa76212dcf14db2796d3b2ad7d`.

The bird, background, ground, pipes, title, Get Ready instructions, Play and Menu buttons, number glyphs, Game Over heading, medals, NEW indicator, and scorecard are cropped directly from that sheet. No generated graphics, recolors, external fonts, added visible text, or other downloaded assets are used. Audio is omitted because the upload contained only a sprite sheet.
