# Asset credits

Flappy Bird was created by **Dong Nguyen / .GEARS**. This browser build follows the supplied v1.3 video reference.

The only runtime asset is the uploaded **Mobile - Flappy Bird - Miscellaneous - General Sprites (v1.3).png**, copied unchanged to `public/assets/flappy/official-v1.3.png`.

SHA-256: `e905c929c0de3d59c565d8903db7f3ca27cd78fa76212dcf14db2796d3b2ad7d`.

The yellow bird, day/night backgrounds, ground, pipes, title, Get Ready instructions, Rate/Play/leaderboard buttons, copyright caption, large and result-screen number glyphs, Game Over heading, medals, sparkle, NEW indicator, and scorecard are cropped directly from that sheet. No generated graphics, recolors, external fonts, added visible text, or other downloaded assets are used. Audio is omitted because the upload contained only a sprite sheet.

The reference video's recording overlays and watermarks are not part of the game and are not reproduced. Rate and leaderboard buttons currently display the original graphics without opening an external service.
