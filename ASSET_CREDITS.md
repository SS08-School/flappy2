# Asset credits

Flappy Bird was created by **Dong Nguyen / .GEARS**. This project is a fangame.

All runtime graphics come from the user-supplied **Mobile - Flappy Bird - Miscellaneous - General Sprites (v1.3).png**, copied unchanged to `public/assets/flappy/official-v1.3.png`.

SHA-256: `e905c929c0de3d59c565d8903db7f3ca27cd78fa76212dcf14db2796d3b2ad7d`.

The original yellow, red, and blue birds, backgrounds, ground, pipes, title, buttons, number glyphs, medals, and result panel are extracted at their native coordinates. Additional interface labels are ordinary system-font text. Button and panel frames use nine-slice rendering of the supplied official graphics. No custom recolors, generated artwork, or procedural replacement sprites are used.

The following sound files were downloaded from [noanonoa/flappy-bird](https://github.com/noanonoa/flappy-bird), pinned to commit [`96b76e61aef26ade2a96967c9d9784a5def8880b`](https://github.com/noanonoa/flappy-bird/tree/96b76e61aef26ade2a96967c9d9784a5def8880b). The upstream audio files are preserved unchanged in `public/assets/flappy/`.

The [upstream README](https://github.com/noanonoa/flappy-bird/blob/96b76e61aef26ade2a96967c9d9784a5def8880b/README.md) credits images to [The Spriters Resource](https://www.spriters-resource.com/fullview/59894/) and audio to [The Sounds Resource](https://www.sounds-resource.com/mobile/flappybird/sound/5309/). The pinned repository has no license file; these credits do not grant or change rights to the original assets.

The original sprite sheet has no snail, cloak, or heart images. Powerups use the official silver and gold medal sprites, and remaining health is displayed as a text counter.
